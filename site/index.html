real engine output · sample session

Real engine output at 120 columns. A statusline never wraps, so it scrolls sideways here.

02 · Arrange

Then drag it into shape.

Every widget is a chip. Drag chips between lines and zones — the preview redraws on every drop.

  1. 01

    Drag from the tray

    Pull any of the 39 widgets onto a line, into its left or right zone.

  2. 02

    Drag to rearrange

    Reorder within a line or move to another. From the keyboard: focus a chip, then Alt + arrow keys.

  3. 03

    Drag back to remove

    Drop it on the tray and it leaves the statusline.

The live configurator is on the desktop version of this page — open it on a larger screen to try it.

03 · Install

One command. Then it’s yours.

It checks Claude Code (2.1.251 or later) and Bun — offering to install Bun if it’s missing — then installs the plugin. Run it again any time to update.

TERMINAL 
$ curl -fsSL https://raw.githubusercontent.com/jinhuang712/claude-super-statusline/main/install.sh | bash

Then run /super-statusline:config in Claude Code and pick a layout. Rather do it by hand, or read the script first? See INSTALL.md.
